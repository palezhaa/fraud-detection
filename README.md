### Структура проекта

| Папка | Что лежит |
|-------|-----------|
| `src/data/` | Часть 1 — генератор синтетических транзакций (коммитим генератор, не данные) |
| `src/rules/` | Часть 2 — rule-based движок, 10 правил детекции фрода |
| `src/features/` | Feature engineering для ML |
| `src/models/` | Обучение модели и метрики (precision/recall/PR-AUC) |
| `tests/` | Юнит-тесты, запускаются в CI на каждом PR |
| `notebooks/` | EDA и эксперименты (output чистится pre-commit'ом) |
| `data/raw`, `data/processed` | Данные — НЕ коммитятся (см. .gitignore) |
| `reports/figures/` | Графики и визуализации |

**Важно:** данные, обученные модели и большие файлы не коммитятся.
Воспроизводимость обеспечивается генератором с фиксированным seed,
а не закоммиченным CSV. Любой клонирует репо, запускает генератор —
и получает те же данные.
